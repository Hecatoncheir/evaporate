# Evaporate UI concept 02

Отдельный интерактивный прототип нового интерфейса. Он не использует и не
дорабатывает текущую Flutter-оболочку.

## Идея

- Контент важнее корпуса: постоянная навигация занимает одну верхнюю строку,
  а обложки получают максимум площади.
- Скевоморфизм проявляется в материале, глубине нажатия и световых индикаторах,
  а не в декоративных ручках и приборах без функции.
- Состояние загрузок не занимает место постоянно: короткий индикатор ведёт на
  самостоятельный экран с очередью и скоростью.
- Сохранения представлены как страховка коллекции: сначала состояние здоровья,
  затем понятная хронология снимков.
- Радиус любой прямоугольной рамки не превышает 12 px. Круглыми остаются только
  LED-индикаторы и кнопка запуска.

## Проверяемые сценарии

1. Поиск и фильтрация библиотеки, включая полезное пустое состояние.
2. Переход от обложки к странице игры и обратно.
3. Запуск игры с немедленной обратной связью.
4. Пауза и продолжение загрузки.
5. Просмотр состояния и истории сохранений.
6. Клавиатурная навигация, `/` для поиска, `Esc` для возврата.
7. Адаптация от широкого desktop-окна до 320 px и `prefers-reduced-motion`.

## Запуск

Из корня репозитория:

```sh
python3 -m http.server 4173
```

Затем открыть `http://127.0.0.1:4173/design/prototype-v2/`.
