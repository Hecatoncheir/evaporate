# Evaporate UI concept 03

Отдельный интерактивный прототип интерфейса библиотеки игр. Вариант 02 не изменяется.

Концепция объединяет кинематографичную подачу выбранной игры с редакционной композицией каталога. Светлая и тёмная темы спроектированы как самостоятельные состояния одной дизайн-системы. Прямоугольные элементы используют радиус не более 12 px.

## Запуск

Откройте `index.html` через локальный HTTP-сервер из корня репозитория.

## Интерактивность

- переключение светлой и тёмной тем с сохранением выбора;
- библиотека, экран загрузки, сохранения и карточка игры;
- поиск по клавише `/`;
- фильтр установленных игр;
- адаптивная компоновка и поддержка `prefers-reduced-motion`.
