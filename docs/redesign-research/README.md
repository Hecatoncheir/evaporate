# Материалы исследования к плану обновления интерфейса

Собраны 24–25 сентября 2026 года агентами-исследователями по коду
`evaporate` (HEAD `169cf63` плюс незакоммиченный B6) и `evaporate_design`
(HEAD `a5e95cf`). Это сырьё для [`../redesign-plan.md`](../redesign-plan.md):
план ссылается сюда из таблицы «Ссылки» у каждой фазы. Документы не
поддерживаются: код уходит вперёд, а они остаются снимком на дату.

| Папка | Что внутри |
|---|---|
| `maps/look.md` | Сопоставление по облику: токены, палитра с расчётом контраста WCAG, шрифты, радиусы, моушн, иконки |
| `maps/structure.md` | Сопоставление по структуре: каркас, разделы, экраны, виджеты, блоки, стражи |
| `maps/effects.md` | Сопоставление по эффектам: что сохраняется, что сливается, что добавляется, часы, настройки, бюджет кадра |
| `readers/ev-*.md` | Конспекты подсистем `evaporate`: тема и стражи, эффекты, оболочка, библиотека, разделы, тесты и планы |
| `readers/ed-*.md` | Конспекты подсистем `evaporate_design`: ядро дизайн-системы, оболочка и стекло, библиотека, разделы, лишнее |
| `probe/` | Пробы, прогнанные при проверке: сборка шейдера в `flutter test`, расчёт контраста, число шагов навигации |

Пути в документах — относительно корня `evaporate`; пути в
`evaporate_design` — с этим префиксом. Номера строк относятся к указанным
выше коммитам.
