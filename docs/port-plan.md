# План переноса интерфейса прототипа

Решение и его причины — `docs/decisions/0013-prototype-ui-as-is.md`. Код
прототипа `evaporate_design` лежит в `lib/ui/ev/` как есть и правится
только под данные и события. Цель — рабочее приложение, связанное со всеми
блоками и событиями. Ветка `port/app`; одна фаза — один коммит после
зелёных ворот (`dart tool/gate.dart`), без пуша до слова владельца.

Пока раздел не перенесён, внутри каркаса прототипа работает его нынешняя
страница: приложение остаётся рабочим после каждой фазы.

| Фаза | Что | Готово, когда |
|---|---|---|
| П0 | Код и тесты прототипа в репозитории, исключение из стражей (0013), эффекты приложения в карточках полки | Ворота зелёные; 272 теста прототипа проходят |
| П1 | Каркас прототипа — оболочка приложения: `NavigationBloc`, окно без рамки (перетаскивание, свои клавиши окна), трей и завершение как были, рейка с показаниями `DownloadsBloc`, строка подсказок по раскладке геймпада; остальные разделы — нынешние страницы внутри каркаса; дневная схема убрана | `main.dart` поднимает каркас прототипа; `--smoke` проходит; переход по разделам с клавиатуры и геймпада |
| П2 | Библиотека: герой по выбранной игре (состояние из `GameStatus` и задачи, главная клавиша с удержанием через `primaryActionFor`), «Продолжить» по `lastPlayed`, полки установленного и качающегося, названия через `ReleaseName`, пустая библиотека и поиск; режимы «Стена», «Терминал», «Пульт» на настоящей библиотеке | Игра запускается, качается и открывается с полки; строки экрана в ARB |
| П3 | Страница игры — лист прототипа: запуск, исполняемый файл, правила и снимки сохранений, Steam, выгрузка `.torrent`, удаление | Всё, что делала прежняя страница, делается с листа |
| П4 | Загрузки: `DownloadsBloc` и `DownloadHistoryBloc` — очередь, пауза, отмена, перестановка, график скорости | Очередь управляется с экрана и геймпада |
| П5 | Сохранения: `SavesBloc` — лента снимков, восстановление, выгрузка и загрузка, папка синхронизации, перенос библиотеки | Восстановление и перенос проходят с экрана |
| П6 | Настройки: каталог прототипа на `SettingsBloc` плюс разделы приложения — прокси, геймпад, уведомления, обновление, журнал, звук | Каждая настройка пишет `SettingsPatched` |
| П7 | Диалоги: добавить по magnet и `.torrent`, поиск установленных, правила, восстановление | Добавление и поиск работают из каркаса |
| П8 | Уборка: прежний интерфейс уходит, тесты переписаны, ворота и CI на трёх системах, `--smoke` | Старых страниц в дереве нет |

Скрыто (данных нет): друзья, профиль и аватар, достижения, оверлей поверх
игры, дайджест. Звук прототипа включён по умолчанию.
